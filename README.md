# কুরবানীর হিসাব

খাইলকুর কেন্দ্রীয় জামে মাস্‌জিদ — কুরবানীকারীদের হিসাব অ্যাপ।

## GitHub Pages-এ চালু করার ধাপ
1. github.com এ নতুন রিপোজিটরি খুলুন (নাম: `qurbani-hisab`, **Public**)।
2. **Add file → Upload files** চাপুন। এই ফোল্ডারের সব ফাইল ও `icons` ফোল্ডার টেনে/বেছে আপলোড করুন → **Commit changes**।
3. **Settings → Pages** এ যান। Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** → **Save**।
4. ১–২ মিনিট পর লিংক পাবেন: `https://আপনার-ইউজারনেম.github.io/qurbani-hisab/`

## মোবাইলে অ্যাপের মতো বসানো
- **Android (Chrome):** লিংক খুলুন → ⋮ মেনু → **Install app / হোম স্ক্রিনে যোগ করুন**।
- **iPhone (Safari):** লিংক খুলুন → Share বাটন → **Add to Home Screen**।

## আপডেট দিলে
`index.html` বদলে আপলোড করুন, আর `sw.js` এর `VERSION = "v1"` কে `"v2"` করুন।

## জরুরি
তথ্য ফোনের ব্রাউজারেই জমা থাকে। নিয়মিত অ্যাপের ভিতরের **ব্যাকআপ** দিয়ে ফাইল নামিয়ে রাখুন।
